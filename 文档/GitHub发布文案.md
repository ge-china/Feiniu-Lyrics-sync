## 首版 Release

- **Tag**：`v0.4.0`
- **标题**：`飞牛歌词同步 v0.4.0 —— 首个可用版本`
- **正文**：

```markdown
首个可用版本。扫描飞牛 NAS 的音乐库，为缺少歌词的歌曲自动补全 LRC。

## 功能
- 曲库扫描，识别 .lrc / .LRC / 双扩展名 / 内嵌标签
- 多源匹配：LRCLIB、网易云、QQ 音乐、酷狗（并行，快源优先、慢源兜底）
- L1~L7 检索阶梯：歌名+歌手 → 去括号 → 繁简转换 → 专辑 → 去副标题 → 仅歌名 → 文件名
- 三种下载模式：全自动 / 多版本时询问 / 全部人工；待确认列表可选版本并记忆
- 写入独立 .lrc 或音频内嵌标签（FLAC / MP3 / M4A）
- 批量删除歌词
- 自定义歌词源（.js 插件）

## 安装
下载附件 `飞牛歌词同步-0.4.0.fpk` → 应用中心 → 手动安装。

安装后请在「应用中心 → 飞牛歌词同步 → 设置 → 授权目录」授权音乐文件夹，否则只能扫描、无法写入。

## 说明
歌词来自第三方公开接口，版权归原作者。本工具仅做个人本地补全，不缓存、不分发。
```
