【原创】飞牛歌词同步 —— 给音乐库自动补全歌词（v0.4.0）

一、这是什么

飞牛 NAS 的音乐下载下来经常没有歌词。这个小工具会扫描你的音乐目录，找出没有歌词的歌曲，自动去匹配带时间轴的 LRC 歌词，写到歌曲旁边（或写进音频标签里）。

二、能做什么

1. 扫描整个音乐库，自动识别已有歌词（.lrc / .LRC / 内嵌标签）
2. 多源匹配：LRCLIB、网易云、QQ音乐、酷狗，按"歌名+歌手+时长"打分
3. 检索有先后顺序：歌名+歌手 → 去括号 → 繁简转换 → 专辑 → 去副标题 → 仅歌名 → 文件名，逐级降级，命中就停
4. 支持三种模式：全自动 / 多版本时询问 / 全部人工确认
5. 写入方式可选：独立 .lrc 文件，或写进音频内嵌标签（FLAC/MP3/M4A）
6. 可批量删除歌词（勾选后一键删）
7. 支持自定义歌词源（放一个 js 文件即可）

三、安装

1. 应用中心 → 手动安装 → 选择 飞牛歌词同步-0.4.0.fpk
2. 首次安装会自动装依赖应用 nodejs_v22（没网的话先自己装好）
3. 装完桌面会出现「飞牛歌词同步」图标

四、重要：先授权目录

应用是以独立用户运行的，必须先授权音乐目录，否则只能读不能写。

应用中心 → 飞牛歌词同步 → 设置 → 授权目录 → 添加你的音乐文件夹（比如 /vol1/1000/Music/音乐）

五、使用

1. 打开应用，填写音乐目录（也可以点「授权目录」自动读取）
2. 点「扫描曲库」，等进度完成
3. 点「自动补全（缺歌词）」
4. 有歧义的歌曲会进「待确认」页，里面列出多个版本（来源/歌名/歌手/专辑/时长/分数），挑一个点「写入这个」
5. 你选过的版本会被记住，下次遇到同一首歌自动用这个版本

六、设置建议

- 下载模式：建议先用「多版本时询问」，跑一批看看匹配质量，稳定后再改「全自动」
- 写入方式：优先「独立 .lrc」，兼容性最好；想要手机端也能看歌词再选「写入内嵌标签」
- 改内嵌标签前建议打开「先备份音频」，多一层保险

七、常见问题

Q：扫描到了歌，但一首都没写进去？
A：多半是没授权目录。扫描时如果没写权限，页面顶部会出现黄色提示条。去「应用设置 → 授权目录」加上音乐文件夹，重新扫描。

Q：为什么有的歌没匹配到？
A：默认要求分数 ≥55 且时长差 ≤5 秒，宁可空着也不写错。可以调低「最低匹配分」，或者用「手动搜索」自己挑。

Q：会不会把我原来的歌词覆盖掉？
A：默认「保留已有歌词不覆盖」，只有勾掉这个选项才会覆盖。

Q：会不会改坏我的音乐文件？
A：写 .lrc 只是新增一个文本文件，不动音频。写内嵌标签会重写文件标签区（音轨数据不变），建议开启备份。
