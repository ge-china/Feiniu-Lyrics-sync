# 使用说明

## 安装
1. 飞牛 NAS → 应用中心 → 手动安装 → 选择 `安装包/musictb.fpk`
2. 首次安装会自动安装依赖应用 `nodejs_v22`（若无网络请先装好）
3. 安装完成后桌面出现「歌词同步」图标

## 授权音乐目录（必做）
应用以独立用户运行，必须先授权目录才能读写文件：
- 应用中心 → 本应用 → 设置 → 授权目录 → 添加音乐文件夹（如 `/vol1/1000/Music/音乐`）
- 或在应用页面点「授权目录」按钮读取已授权路径

## 使用
1. 打开「歌词同步」
2. 填写/选择音乐目录 → 点「扫描曲库」
3. 点「自动补全（缺歌词）」，等待进度完成
4. 需要指定版本时：曲库列表 → 「手动搜索」 → 挑选候选 → 「写入」
5. 设置里可选：写 .lrc / 写内嵌标签 / 两者都写

## 自定义源
把 .js 文件放进数据目录的 `sources/`（页面「自定义源」标签能看到完整路径），
格式见页面模板：

```js
export const id = 'my-source';
export const label = '我的源';
export async function search(track) {
  // track = { title, artist, duration }
  return [{ title: '', artist: '', album: '', duration: 0, lrc: '[00:00.00]...' }];
}
```

保存后在「设置 → 歌词源」里勾选启用。

> 自定义源执行的是用户自己的代码，请只放可信文件。

## 状态说明
- 已有：检测到 .lrc 文件或内嵌歌词
- 缺失：两者都没有
- 未匹配：搜到了候选但分数低于阈值，或没搜到

## 删除歌词
1. 曲库列表勾选一首或多首（表头复选框可全选）
2. 选删除范围：跟随写入方式 / 仅删 .lrc / 仅清内嵌 / 两者都删
3. 点「删除所选歌词」，确认

- 删除是**直接删除**，不可恢复（.lrc 文件被移除，内嵌标签被清空）
- 单首删除：曲库列表每行的「删歌词」按钮
